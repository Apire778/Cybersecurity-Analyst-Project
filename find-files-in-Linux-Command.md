### Get current directory information
## Display your working directory.
**Command:**
```bash
pwd
```

**Output:**
```
/home/analyst
```

**Explanation:**
This confirms your current working directory is your home directory — useful as a starting reference point before running relative-path searches.

## Display the names of the files and directories in the current working directory.
**Command:**
```bash
ls
```

**Output:**
```
logs  projects  reports  temp
